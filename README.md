# yita-seat

YITA 座位手冊:用 YITA Builder 的 MCP 工具排頁、畫樣式草稿層、回報收回。

## 手冊(照順序讀)

- [座位鐵則 — 先讀、牢記、不能忘](01-seat-rules.md)
- [座位開始指南 — 接上 Builder、開工前拿什麼、卡住看哪](02-seat-setup.md)
- [畫頁手冊 — 畫稿怎麼寫才收得回](03-page-draw-guide.md)

## Claude Code 安裝

```
/plugin marketplace add https://github.com/ArvinHsiao/yita-seat
/plugin install yita-seat@yita-seat
```

裝好後會帶兩條 YITA Builder 連線(正式版 `https://builder.hauzii.com/mcp` / DEV `https://builder-dev.hauzii.com/mcp`),第一次使用時用 Google 帳號登入。

## 其他工具(Claude Desktop / ChatGPT / Codex …)

用 GitHub 連接器讀這個 repo 的三本手冊;Builder 連線加一個自訂 MCP 連接器,網址填 `https://builder.hauzii.com/mcp`,一樣用 Google 登入。
